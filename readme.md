# 目的
ホテル「森に浮かぶ集落」の持分所有権を持つオーナーが、自分の宿泊可能日数の範囲内で宿泊予約をするためのサイト

# 制約
- ビルドツール（Vite, Astroなど）は使用しない
- JavaScriptは必要最小限のみ
- Node.js不要
- 完全な静的構成とする

# ディレクトリ構成
- ルートに index.html を配置
- 静的ファイルは assets/ 配下に集約する
  - css, images, js に分割

# パス設計
- 相対パスで記述する
- GitHub Pagesで動作するようにする
- Live Serverでそのまま動作すること

# 要件
- 各ページは単体で表示可能にする
- 共通CSSを使用する
- semantic HTMLを使用する

# 開発体験
- VSCode + Live Serverで保存時に自動リロードされる前提
- index.html からリンク遷移できること

# ページ内容
最初にログインを求める。ログイン画面では、森に浮かぶ集落の写真を表示し、オーナー宿泊予約サイトであることを表示する。
テスト用のIDは"testid"、PWは"testpw"

ログインが成功すると、トップページが表示される。
トップページでは、以下の情報を表示する。
- 自分が所有している物件の概要
 - 森に浮かぶ集落
- 自分が保有している宿泊可能残り日数
- 自分が保有している物件の宿泊予約カレンダー

宿泊予約カレンダーの空いている日程を選択して、宿泊可能残り日数以内であれば、予約確認ページを表示する。
予約確認ページでは、予約する日程やチェックイン、チェックアウト時間を入力して予約の確定を行う。
